# 🧮 Advanced Scientific Neumorphic Calculator

A sleek, professional-grade scientific calculator built with **HTML5, CSS3 (Neumorphism), and Vanilla JavaScript**.

## ✨ Features
* **Scientific Functions**: Includes `sin`, `cos`, `tan`, and `sqrt` calculations.
* **Neumorphic UI**: A modern 3D soft-shadow design for a tactile feel.
* **Responsive Design**: Works perfectly on desktops and mobile devices.
* **Error Handling**: Built-in `try...catch` logic to handle invalid mathematical expressions gracefully.

## 🛠️ Built With
* **HTML5**: Semantic structure.
* **CSS3**: Custom Neumorphic styling and animations.
* **JavaScript**: Advanced math logic using the `Math` object.
